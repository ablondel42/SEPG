# Artifact Management Rules - DIARY Directory

- **Systematic Copy to DIARY:** For every plan, task,
or artifact generated during development (e.g.,
`implementation_plan.md`, `walkthrough.md`, task lists,
progress reports), immediately save or copy a version
into the `DIARY/` directory located at the root of the
project.
- **Preservation and Traceability:** Ensure that the
`DIARY/` directory is created if it does not already
exist, and maintain all planning documents organized and
timestamped to ensure complete traceability of the
project history.
